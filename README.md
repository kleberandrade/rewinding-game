Unity game source project with camera, gameplay and interface assets.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Gameplay 2.unity](https://github.com/kleberandrade/rewinding-game/blob/master/Assets/Scenes/Gameplay%202.unity), [Assets/Scenes/Gameplay.unity](https://github.com/kleberandrade/rewinding-game/blob/master/Assets/Scenes/Gameplay.unity), [Assets/Scenes/MainMenu.unity](https://github.com/kleberandrade/rewinding-game/blob/master/Assets/Scenes/MainMenu.unity), [Assets/Scenes/SelectLanguage.unity](https://github.com/kleberandrade/rewinding-game/blob/master/Assets/Scenes/SelectLanguage.unity).
